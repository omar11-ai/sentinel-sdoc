L1 · TRIAGE

Classifies every email into 5 categories. Rules cues first, fast LLM assist when configured; disagreement is recorded, never hidden.

L2 · EXTRACT

Seven canonical fields from txt / PDF / XLSX / DOCX with synonym + qualifier normalization (CJK-safe). A conditional multi-agent court convenes only for low-confidence documents.

L3 · VERIFY

An adversarial pass tries to break each extraction with counter-evidence from the same document. Advisory by default; enforcing only by measured decision.

L4 · COMPARE

Typed comparison — numbers as numbers, port codes stripped, blanks are uncertainty not defects. SI is the reference.

L5 · JUDGE

Four canonical escalation reasons (wrong_doc_type · missing_attachment · unreadable · missing_value) with human-readable evidence. The system refuses to guess.

🛡 · SANITIZER

Prompt-injection screening before any LLM sees a document. Detection flags are surfaced, never obeyed.
